# OASF Crosswalk

OASF-style agent taxonomies describe agent categories and capabilities. Work IQ Open Format adds Git-native authoring, validation, and provenance expectations for operational use.

| Work IQ Open Format field/object | OASF alignment | What OASF covers | What this profile adds |
| --- | --- | --- | --- |
| Agent type and capabilities | Agent taxonomy entries | Agent classification and capability labels | Required trust metadata and lifecycle state |
| Discovery metadata | OASF discovery descriptors | Interoperable discovery concepts | Bundle manifest integration and conformance claims |
| Skills | Capability or skill taxonomy | High-level skill naming | Markdown bodies, evidence, and approval constraints |
| Safety and approval rules | Policy descriptors | General policy categories | Review-ready authoring format with stale handling |
| Memory scope | Agent policy metadata | Some runtime behavior expectations | Explicit retention boundaries for governance |
